# Compile reviewed adapters and keep theme packs data-only

Adapters can run commands, request permissions, and modify configuration, so Oh My Theme will compile reviewed adapters into signed app releases rather than load executable community plugins. Theme packs may be installed independently but contain only colors, metadata, attribution, and assets. Community adapter contributions can enter through review, and a declarative adapter format will wait until several implementations prove one narrow repeated shape.
