# Resolve themes from pinned upstream ports or semantic generation

Oh My Theme supports Workspace policies that prefer pinned upstream ports, require upstream ports, or choose semantic generation. The default prefers a pinned, attributed upstream port and falls back to generated output. It will not merge upstream and generated files. This preserves community-maintained target fidelity while retaining a path for original and incomplete themes, and it keeps the source of every applied artifact explicit.
